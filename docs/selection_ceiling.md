## 解读

1. **NYU val：上限明显高于硬屏蔽。**6 个模型的上限比硬屏蔽低 21–52%，干净像素的误差能基本回到原始提示的水平（例如 LingBot 0.083 → 0.013，OMNI-DC 0.071 → 0.015）。也就是说，镜面上的过度屏蔽在原则上可以完全避免。
2. **NYU 留出场景：除 PromptDA-L（−22%）外上限接近硬屏蔽**（0–3%）。这些图像里硬屏蔽已经接近最优。
3. **HAMMER 交叉拟合（10 个场景）：**
   - CDM 的上限比硬屏蔽低 19%。它在 scene4 和 scene5 上可纠正空间为负，硬屏蔽反而更差（scene5：A 0.055，B 0.104），而选择上限是 0.045，负收益可以完全避开。
   - PriorDA 和 OMNI-DC 低 10%，LingBot 和 Any2Full 低 5–6%。
4. **上限偏乐观**：它由真值做选择，32×32 的块已经比逐像素粗得多，但可学习的门控只能拿到其中一部分。
5. **结论**：在硬屏蔽有害的两类情形（镜面上的过度屏蔽、可纠正空间为负的场景）里，选择门控有可观的空间；在硬屏蔽已经接近最优的情形里，空间很小。值得训练一个可学习的门控，并以这两类情形为主要目标。
