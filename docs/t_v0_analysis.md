# T v0 结果分析（小规模验证通过，非正式结果）

运行：`scripts/windows/step5_t_v0.ps1`，用时 2 小时 11 分。表格见 `docs/trust_v0_results.md`。T 只在 train split 上训练，并在 train 的留出场景上选择 checkpoint 和阈值；val 没有参与。

## 1. 可信度排序：T 明显优于免训练方法

逐场景平均 AUROC（干净提示像素为正类），只看样本外的 val 和 train 留出场景：

| | NYU val | NYU 留出 | HAMMER val | HAMMER 留出 |
|---|---:|---:|---:|---:|
| Gate | 0.811 | 0.864 | 0.691 | 0.682 |
| DEPTHOR++ 式检测器 | 0.794 | 0.794 | 0.730 | 0.688 |
| T v0 real | 0.928 | 0.963 | 0.935 | 0.953 |
| T v0 sim | 0.874 | 0.948 | 0.840 | 0.888 |
| T v0 real_sim | 0.837 | 0.909 | 0.893 | 0.914 |
| T v0 real_sim 不用编码器特征 | 0.885 | 0.953 | 0.849 | 0.914 |

## 2. HAMMER 物体：T 掩码 + PromptDA-L 是最好的可部署组合

C AbsRel：val 0.0334、留出 0.0302。检测器为 0.0362 / 0.0365，Gate 为 0.0512 / 0.0505，GT 掩码上界（val）为 0.0321。T 把检测器与上界之间约 70% 的差距补上了，IR 和 DOR 也同步下降。val 和留出各只有 1 个场景，所以只能作描述，不能做场景级检验。

## 3. NYU 镜面：还没有收益，原因是漏检

- PromptDA-L + 掩码：在 val 上所有方法都接近 GT 掩码上界（0.096–0.100）。T 相对 Gate 的配对差为 +0.002 [−0.009, +0.012]（16 个场景），没有区别。在留出场景上，T 为 0.194，比 Gate 的 0.166 差。
- 直接测量掩码（被污染的镜面像素中被标记的比例 = 召回；干净像素中被误标的比例）：

| | val 召回 | val 误标 | 留出召回 | 留出误标 |
|---|---:|---:|---:|---:|
| Gate | 0.863 | 0.210 | 0.926 | 0.168 |
| T real（被选中的版本） | 0.600 | 0.013 | 0.825 | 0.009 |
| T sim | 0.695 | 0.040 | 0.804 | 0.015 |
| T real_sim | 0.751 | 0.034 | 0.774 | 0.029 |
| T 不用特征 | 0.797 | 0.065 | 0.900 | 0.040 |

- T 非常“保守”：误标极少，但漏掉了 10–40% 的镜面污染。漏掉的像素保留了错误提示，误差很大，被继承下来；而误标一个干净像素，代价只是用 D_g 或 PromptDA 补一下。两种错误的代价明显不对称。
- 阈值按全图像素 F1 选择，没有体现这种不对称；版本选择按全图 AUROC，主要由背景像素决定，没有对准主范围（镜面 / 物体）。结果被选中的 real 版本在 HAMMER 上最好，在 NYU 镜面上却最差。
- 填充路径：T（不用特征）+ 填充在 NYU 留出场景上为 0.118，好于全局对齐 0.163 和 Gate + 填充 0.161；但在 val 上为 0.145，相对全局对齐的配对差为 +0.010 [−0.055, +0.096]，不显著。

## 4. 局限

NYU 的样本外数据只有 val 17 帧和留出 8 帧（含镜面污染的帧），结论很不稳定。大面积污染（镜子、玻璃）的数据量是检验主张的主要瓶颈。

## 5. 建议：T v1（只改选择和阈值，不扩大模型）

1. **代价敏感的阈值与版本选择**（只用 train 留出场景）：以“按掩码替换为 D_g 后的深度误差”作为选择目标，在主范围和全图上分别计算。这需要在训练数据里加存 GT（重建数据，CPU）。
2. **区域一致的掩码后处理**：对标记出的连通区域做闭运算和内部孔洞填充，镜面是连贯区域。先在留出场景上看召回和误标的变化。
3. **特征正则化**：不用特征的版本在 NYU 上召回更高，说明在小数据上特征可能导致过拟合。加 dropout，或在少量数据上冻结投影层；保留不用特征的版本作为消融。
4. **补镜面数据**：MP3D / ScanNet 镜面子集需要签使用协议，另有自采镜子和玻璃场景。仍是决定主张能否成立的关键。
