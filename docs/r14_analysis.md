# R14 实验结果：选择规则与 DEPTHOR++ 式检测器（小规模验证通过，非正式结果）

数据：NYU val 19 帧 / train 76 帧（镜面范围）、HAMMER val 327 张 / train 816 张（物体范围），只用 train/val。完整表格见 `docs/selection_results.md`。配对检验（场景 bootstrap，95% CI，未做 Holm，仅作描述）：`results/mirror3d_dev_paired_r14_train_v1`、`results/mirror3d_dev_paired_selection_train_v1`、`results/hammer_dev_paired_r14_train_v1`。

## (b) 选择规则：没有通过预先设定的判据

预先设定的判据（R14）：在 NYU train 和 val 上，都要把 v1 与逐区域神谕之间的差距缩小至少三分之一。

| 差距缩小比例 | NYU val | NYU train | HAMMER val | HAMMER train |
|---|---:|---:|---:|---:|
| AIC | 0.00 | 0.00 | 0.00 | 0.00 |
| GRIC | −0.16 | +0.14 | −0.22 | −0.84 |
| 扇区留出 | −0.20 | −0.04 | −0.06 | −0.50 |
| 径向留出 | 0.00 | +0.03 | −0.60 | −1.17 |

- NYU train 上相对 v1 的配对差：GRIC −0.009 [−0.022, +0.002]，扇区留出 +0.002 [−0.008, +0.013]，径向留出 −0.002 [−0.017, +0.012]，均不显著；神谕选择 −0.061 [−0.095, −0.033]。
- AIC 与 v1 的选择完全相同：环带点数达到上千时，k·log n 和 2k 这两项惩罚相对 n·log RSS 都可以忽略。
- 所有规则选中逐区域最优候选的面积比例都只有 0.3–0.56。只看环带上的统计量，无法判断区域内部哪个候选最好；神谕选择的优势来自区域内部的信息。
- **结论**：保留 v1，不把留出验证作为贡献。要缩小差距，必须用到区域内部的信息（图像特征、T 的输出），也就是学习式选择。这需要单独做实验，暂不写成贡献。

## (a) DEPTHOR++ 式检测器：接 PromptDA 很强，接填充很弱

C AbsRel（主范围）：

| | NYU val | NYU train | HAMMER val | HAMMER train |
|---|---:|---:|---:|---:|
| 全局对齐 | 0.135 | 0.128 | 0.092 | 0.110 |
| PromptDA-L | 0.467 | 0.617 | 0.043 | 0.043 |
| PromptDA-L + 检测器掩码（论文阈值） | 0.101 | 0.247 | 0.039 | 0.038 |
| PromptDA-L + 检测器掩码（关闭门控） | 0.100 | 0.212 | 0.036 | 0.039 |
| PromptDA-L + GT 掩码 [oracle] | 0.096 | 0.131 | 0.032 | — |
| GT 掩码 + 填充 v1 [oracle] | 0.090 | 0.100 | 0.059 | 0.080 |
| 检测器 + 填充 v1 | 0.312 | 0.389 | 0.138 | 0.179 |
| Gate + 填充 v1 | 0.152 | 0.124 | 0.094 | 0.113 |
| 可信度 AUROC：检测器 / Gate | 0.80 / 0.81 | 0.78 / 0.84 | 0.73 / 0.69 | 0.69 / 0.70 |

1. **“检测 → 屏蔽 → PromptDA”这一 DEPTHOR++ 范式在我们的数据上很强。** 相对 PromptDA-L 的配对差：
   - NYU train 镜面：−0.370 [−0.486, −0.261]（论文阈值）、−0.405 [−0.516, −0.298]（关闭门控）。
   - HAMMER train 物体：−0.005 [−0.009, −0.003]（论文阈值）。
   这是 T 必须超过的可部署基线。
2. **T 的提升空间集中在大面积污染上。**
   - HAMMER 小物体：检测器版 0.036–0.039，GT 掩码上界 0.032，即使 T 完美，也只能再降约 0.004–0.007。
   - NYU 镜面（train）：检测器版 0.212，GT 掩码 + PromptDA 0.131，GT 掩码 + 填充 0.100，逐区域神谕 0.038，空间很大。
   - 这与 R13 的判断一致：方法的价值在大面积、连贯的错误提示上。
3. **检测器接填充时很弱。** 论文门控在 NYU 上关掉了约一半的帧（val 10/19，train 40/76），未被标记的错误提示原样保留，继承率 IR 0.5–0.97。在填充路径上，检测器比免训练的 Gate 差得多。所以检测器的作用主要体现在“屏蔽后交给 PromptDA”。
4. **可信度排序能力**：检测器分数与免训练 Gate 的 AUROC 接近（0.69–0.84），两者都远不完美。这正是 T 要证明的地方：同样接 PromptDA 时，T 的掩码是否更接近 GT 掩码。

## 对计划的影响（建议）

- 贡献 3（验证式选择）取消。逐区域选择改为将来与 T 结合的学习式选择，作为备选实验，不进入主线。
- T v0 的主评测：
  - 主组合：T 掩码 + PromptDA-L，以及 T 掩码 + 填充 v1。
  - 必须对比：检测器（两种阈值）+ PromptDA-L，Gate + PromptDA-L。
  - 上界：GT 掩码 + PromptDA-L、GT 掩码 + 填充 v1。
  - 报告重点：NYU 镜面这类大面积污染。
- 缺一个格子：Gate 掩码 + PromptDA-L 还没有跑。成本很低，需要在 Windows GPU 上跑一次。
