# 相关工作审计（2026-10-15）

来源：一次文献调研（2024–2026，arXiv / CVF / 项目页），由我们按自己的数据核对后整理。“未见先例”只代表那次检索范围内没有找到。数字都取自原论文，各家协议不同，**不能和我们的开发集数字直接比较**。

## 1. 各组件的判定

| 组件 | 判定 | 最接近的先例 | 我们必须证明的 |
|---|---|---|---|
| 提示继承分析 + IR / DOR + 按提示误差定义污染区 | 较新，作为诊断和基准贡献 | DEPTHOR++ 提到错误测量会误导补全；GlassRecon 观察到 PriorDA 被传感器深度带偏；Mirror3D 指出补全方法在镜面上严重出错。三者都没有量化继承率 | 在多个提示式模型和多种传感器上都成立；继承程度与污染面积的关系要给出置信区间 |
| 可信度网络 T + 物理污染模拟器 | 增量，但可以辩护 | DEPTHOR++：无参检测器，训练时模拟“缺失 / 错误”区域；CDM：按相机学习隐式噪声模型；OMNI-DC：内部置信图；Perfecting Depth：用扩散采样方差找不可靠区 | 模拟器各成分的消融；跨传感器、跨数据集的 AUROC；作为插件能提升至少 3 个下游模型 |
| 屏蔽 + D_g 填充 + PromptDA | 已有先例，只作基线 | DEPTHOR++ 评测 PromptDA 时用 DAv2 线性拟合后填洞；PriorDA 用先验预填充再细化；GlassRecon 用鲁棒全局对齐 | 不作为贡献 |
| 提示修复（环带低自由度拟合 + BIC） | 增量偏弱，且有协议风险 | Mirror3DNet 用镜面掩码外 25 像素带确定平面偏移；PriorDA 用 KNN 局部尺度 / 偏移预填充 | 必须在非平面真值数据上显著有效 |
| 错误提示作为单侧约束（R16 新方向） | 检索范围内未见 | 相关工作都是丢弃或屏蔽错误值 | 约束确实携带信息（HAMMER 上界紧），而且模型能学会利用 |
| 可信度通道注入 PromptDA | 检索范围内未见 | PriorDA 的零初始化条件分支；LingBot-Depth 的 token 掩码（只屏蔽无效像素） | 明显优于硬掩码和修复，并在 T 出错时依然稳健 |

## 2. 主要相关工作的做法

- **DEPTHOR++**（arXiv 2509.26498）：用 DAv2 相对深度做全局排序与局部相似性两项一致性检查，按 Spearman 系数分段确定阈值，把检出的点改成缺失，再交给补全网络。作者承认在镜面这类大面积均匀区域会失效。我们已复现该检测器（复现偏差见 decisions §11）。
- **LingBot-Depth 1.0 / 2.0**（arXiv 2601.17895 / 2607.05247）：掩码深度建模，只把无效像素当掩码；有值但错误的像素照常进入模型。它在 HAMMER 上报告了按传感器的全图 RMSE 和 D105，是最强的通用对比方法，也最适合“接 T 掩码”（把不可信像素置为无效）。
- **CDM**（arXiv 2509.02530）：按相机学习空洞和数值噪声模型，用在合成数据上训练去噪网络。有 Kinect / L515 / D435 专用权重，纠错是隐式的。
- **PriorDA**（ICLR 2026）：对缺失像素用 K 个最近有效点局部拟合尺度和偏移进行预填充，再用零初始化条件分支细化。
- **OMNI-DC**（ICCV 2025）：网络内部预测稀疏输入的置信度；作者承认在玻璃和反射表面上会出错。
- **GlassRecon**（arXiv 2604.18336）：在 patch 内随机采样尺度和偏移、在全图上投票，做鲁棒全局对齐，免训练。它的真值是在共面点上拟平面得到的。
- **Mirror3D / Mirror3DNet**（CVPR 2021）：镜面平面由镜框边缘深度经 RANSAC 求得，再人工微调；Mirror3DNet 用掩码外边界带的深度确定平面偏移。
- **透明物体**：ClearGrasp、TransCG、TDCNet、HDCNet、TCG-Depth（显式置信加选择性修正），以及完全不用传感器深度的 DKT。

## 3. 投稿前必须处理的协议风险（按严重度）

1. **Mirror3D 真值与平面填充同源**：NYU 上平面类方法的收益会显得偏高，主要证据要放在非平面真值数据上。
2. **NYU 划分不是官方划分**（decisions §16）：要和已发表结果比较，需要按官方划分重训和评测。
3. **样本量**：NYU 样本外镜面帧只有 25 帧；HAMMER 的 val 和留出各 1 个场景。要做 bootstrap 区间和 Holm 校正。
4. **只看污染像素会掩盖过度屏蔽**：同时报干净区域、全图指标和误标率（DEPTHOR++ 自己就出现了“其他区域”变差）。
5. **输入形态不同**：DEPTHOR++ 用稀疏 dToF 点，我们用稠密 Kinect / RealSense；复现时的采样方式要写清楚。

## 4. 数据集（缓解镜面数据瓶颈）

- Mirror3D（Matterport3D / ScanNet 部分）：需要签使用协议；那里的镜面像素多数是缺失而不是错误值。
- TransCG（CC BY-NC-SA 4.0）、ClearPose：透明物体，真值不是平面拟合，适合检验 T 的跨数据泛化和“修复”。
- GlassRecon：玻璃区域有错误值，但真值同样是平面拟合。
- 自采数据（R16 第 3 项）：多传感器的镜面和玻璃场景，真值不用平面拟合，同时解决数据量和真值同源两个问题。

## 5. 补充核查：训练代码是否公开，以及最新工作（2026-10-18）

这一节服务于“选一个最新的开源框架作 baseline，在框架内部针对‘提示有错’这个条件设计模块”的思路，所以重点看能不能训练。核查方式：克隆各官方仓库，查看其中的文件和 README（commit 日期如表），再读论文与项目页。

**结论：**

1. 这些新框架里，**只有 OMNI-DC 公开了完整训练代码**。PromptDA、PriorDA、Any2Full、LingBot、CDM 都只有推理代码。
2. 想在框架内部加模块并训练，可行的路线有三条：
   - (a) 在 OMNI-DC 上从官方权重微调（有训练代码；它在 NYU 镜面上照抄错误的比例为 0.93，最严重）；
   - (b) 自己写 PromptDA 的微调代码（结构简单，权重公开，但要复现它的数据流程）；
   - (c) 选不需要训练的 Marigold-DC：把“提示有错”这个条件写进它的测试时引导目标，例如按可信度加权的鲁棒引导，再对测远型像素加单侧约束（真实深度 ≤ P）。不用训练 GPU，但每张图要 30–60 秒，而且 Marigold-DC 的继承率我们还没测过。
3. MetricAnything 用提示的教师模型和 LingBot-Depth 2.0 都没有公开权重，暂时无法测它们的继承率。这两项是最直接的潜在竞争工作，权重放出后要第一时间补测。
