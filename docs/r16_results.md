# R16 第 1、2 项结果（小规模验证通过，非正式结果）

运行：`scripts/windows/step8_bounds.ps1`（3 小时 8 分）。完整表格见 `docs/bound_results.md`。C AbsRel 只看主范围（NYU 镜面 / HAMMER 物体）；val 和 train 留出场景对 T 都是样本外。

## 0. 复现检查

已随 E 盘删除的 HAMMER“PromptDA-L + T v1 掩码”缓存，用恢复后的源码和权重重新生成：val 327/327、train 816/816 张预测**逐位一致**。HAMMER 的 GT 掩码缓存在 val 上也与旧结果一致（0.0321）。这说明恢复的源码和权重与原来完全相同，整套流程可以复现。

## 1. 上界截断：按预设判据，盲目截断不成立

| C AbsRel | NYU val | NYU 留出 | HAMMER val | HAMMER 留出 |
|---|---:|---:|---:|---:|
| PromptDA-L + T v1（模型阈值） | 0.0942 | 0.1617 | 0.0344 | 0.0293 |
| + 截断 | 0.0942 | 0.1595 | 0.0345 | 0.0293 |
| PromptDA-L + T v1（conformal α=0.1） | 0.0959 | 0.1650 | 0.0340 | 0.0292 |
| + 截断 | 0.0947 | **0.1512** | 0.0342 | 0.0293 |
| PromptDA-L + GT 掩码 [oracle] | 0.0958 | 0.1656 | 0.0321 | 0.0310 |
| + 截断 [oracle] | **0.0927** | **0.1511** | 0.0364 | 0.0324 |

- 预设判据是“截断让 HAMMER 物体的误差下降，且 val 与留出方向一致”，结果**不成立**：用 T 掩码时基本不变，用 GT 掩码时反而变差，IR 也上升。
- NYU 镜面上截断一致地有小幅收益，全图 C 的收益更明显（例如 GT 掩码 val：0.1356 → 0.0998）。
- **原因（追加诊断，GT 掩码，HAMMER 每 4 张取 1 张）**：被污染的像素里约 4% 是“测近了”（P < GT），上界对它们不成立；而 PromptDA 在这些像素上的预测经常大于 P，所以盲目截断会把它们往错的方向拉。

| GT 掩码 + PromptDA-L，HAMMER | val（81 张） | 留出（24 张） |
|---|---:|---:|
| 不截断 | 0.0319 | 0.0319 |
| 截断所有被标记像素 | 0.0361 | 0.0329 |
| **只截断“测远了”的像素（真实类型）** | **0.0304** | **0.0312** |

- 结论：上界约束确实有信息量，但**必须知道误差的方向**（测远了还是测近了）。这直接支持 §3.7.2 的设计：T 要输出约束类型，而不只是可信或不可信。免训练截断的收益很小（约 5%），要靠模型学会利用约束才可能更大。

## 2. conformal 阈值的下游效果

- 风险保证本身见 `docs/conformal_results_d20.md`：α = 0.1 时，NYU 和 HAMMER 的 val 风险都 ≤ α。
- 下游 PromptDA-L：C AbsRel 与模型阈值基本相同（NYU val 0.0959 对 0.0942，留出 0.1650 对 0.1617；HAMMER 0.0340 对 0.0344，0.0292 对 0.0293）。IR 一致下降（NYU 留出 0.082 → 0.061，HAMMER val 0.137 → 0.129），全图 C 在 HAMMER 上变好（0.0519 → 0.0488）。DOR 有升有降。
- 结论：conformal 阈值在不损失精度的前提下，给出了“危险提示被漏掉的比例”的保证，可以作为“保证”这部分贡献；它和截断叠加时，在 NYU 留出场景上最好（0.1512）。

## 3. 下一步

1. T v2 输出三类：可信、测远了（上界）、测近了（下界或未知）。训练数据里已经有符号信息（真实标签由 P 与 GT 比较得到，模拟数据有远 / 近类型），只需改输出头和损失，GPU 约 30 分钟。然后检验“按预测类型截断”能不能接近“按真实类型截断”的收益。
2. 训练带约束通道的补全模型（需要租 GPU）：让模型学会利用上界，而不是只在事后截断。
3. 样本量仍是主要限制：NYU 样本外镜面帧 25 帧，HAMMER 的 val 和留出各 1 个场景。
