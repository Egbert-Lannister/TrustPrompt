# 第 3 步：填充模块 C 的上界分析（小规模验证通过，非正式结果）

数据：NYU train（76 帧 / 55 场景；镜面范围 49 个非空场景，6 个空场景已排除并列出）、NYU val（19 帧）、HAMMER val（327 帧 / 1 场景）、HAMMER train（816 帧 / 9 场景）。测试集未读取。
完整表格：`docs/dev_results.md`、`docs/hammer_dev_results.md`。配对检验：`results/mirror3d_dev_paired_fill_train_v1`、`results/hammer_dev_paired_fill_train_v1`（场景配对 bootstrap，10k，95% CI；**未做 Holm 校正，仅作描述**；HAMMER 只有 9 个场景，区间偏宽）。

`oracle_*` 使用由真值得出的掩码，是上界而不是方法；`gate_global` 是唯一可部署的组合。

## 2. 结论

1. **镜面（大面积、共面）上，低自由度填充有效，但选择是瓶颈。** 在真值掩码下，v1 比全局对齐显著更好，但离逐区域神谕选择还差约 0.06。单一最优候选在两个划分间翻转（val 上是 k2，train 上是 k3），说明不能靠固定一个候选，需要更好的选择规则。注意 Mirror3D 镜面真值是平面拟合得到的，k3 的数字偏乐观。
2. **小物体（HAMMER）上，低自由度填充不如 PromptDA。** 即使有真值掩码，填充也显著差于 PromptDA-L；而 PromptDA-L + 真值掩码是物体上最好的组合（0.032）。在 HAMMER 上，神谕选择（0.055）与 v1（0.059）接近，所以瓶颈不在选择，而在候选族本身：k0–k2 都继承了 D_g 的物体形状，单目先验的小物体形状不够好。k3 有害（0.134 / 0.205），v1 大多正确地避开了 k3。
3. **没有好的可信度判断，填充没有收益。** Gate + v1 在 NYU train 上与全局对齐无差别（区间跨 0），在 val 上更差，在 HAMMER 上显著差于 PromptDA-L。T 是必需的，这与 val 上的结论一致。

## 3. 对方法的含义（建议，待确认后写入修订）

- T 之后分两路：大面积、近似平面的低可信区域 → 模块 C 低自由度填充；小物体 → 把低可信区域从提示中屏蔽，交给 PromptDA（模块 D）。路由可以按区域面积和环带平面性来定，先用上界数据选阈值（只用 train/val）。
- 选择规则 v2 候选：把 BIC 换成环带分扇区留出验证（在留出扇区上比较 k0–k3 的误差），开销小，可在 NYU train/val 上直接比较，作为 T v0 之外的并行小任务。
- 优先级不变：下一步仍是 T v0（DINOv2-S 特征缓存 + T 网络 + 模拟器数据）。
