1. 在全局剩余时间内使用现有 `--pilot-minutes` 机制作计时保护，仍以全部 16,666 步为目标。正常到时且未达到目标时，记录预算耗尽并停止，不声称训练完成。

四阶段按 F0 训练 → F0 零步收尾 → F1 指定检查点续训 → F1 零步收尾串行运行。每阶段保存独立 receipt 快照；F1 之前的 pilot 小文件另存 `pilot_before_resume/`。正常收尾后通过 CPU mmap 验证 `last.pt` 和 `final.pt` 的模型张量完全相同且有限，优化器/RNG、源码/配置合同和训练帧清单一致，才允许整个作业标记 completed。
