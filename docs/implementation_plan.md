## 0. 一页概览

**任务定义**
- 输入：RGB 图像 `I`、任意传感器给出的深度 `P`（iPhone LiDAR 256×192、Kinect/结构光 640×480、RealSense、ToF 等），以及可选的传感器置信度 `c`。
- 输出：度量深度 `D̂`，以及逐像素提示可信度 `w ∈ [0,1]`。可信度可直接当作不确定度用。

**要解决的失效**：传感器在镜子、玻璃、金属上会返回“有效但错误”的深度：
- 镜子返回镜中虚像的深度；
- 玻璃返回背后物体的深度；
- 金属出现多径偏差或掉点。

现有提示式补全模型（PromptDA、PriorDA 等）把这些值当作可靠锚点，结果继承了错误。

**方法由五个模块组成：**
1. 冻结单目先验 + 逐块鲁棒对齐（不学习，产出特征和候选）；
2. 可信度网络 T：预测每个提示像素是否可信，以及错误类型；
3. 低自由度区域填充：在低可信连通域内，从先验/平面等 5 个候选中选一个，平面用 1/Z 仿射的 3 自由度；
4. 改造后的 PromptDA：提示重写 + 可信度通道注入 + 鲁棒归一化；
5. 污染模拟器：为训练提供“干净提示 / 污染提示”成对样本。

**论文三个主张**
- C1：提示式补全会系统性继承错误提示，标准评测（全图平均、仿射对齐）看不到；
- C2：本方法在留一传感器设置下显著降低污染区域度量误差，干净区域不退化；
- C3：收益来自识别错误提示，而不是材质分割；污染模拟的类型和低自由度填充各自有贡献。

**本次核实过的代码事实**（直接读了官方仓库；两者都是 Apache-2.0）

- **PromptDA 的输出被提示的取值范围卡住**（`promptda/promptda.py`）：
  - 先用提示的 0% / 100% 分位数（即最小、最大值）把提示归一化；
  - 网络输出层是 sigmoid，最后再用同一对 min/max 反归一化，所以输出只能落在 `[min(P), max(P)]` 之间；
  - 镜子返回的虚像深度往往是全图最远的值，会把 max 拉大，改变整张图的映射；
  - 传感器的空洞若编码为 0，会把 min 拉到 0。
  
  这是“继承”在结构上的直接成因之一。
- **PromptDA 的提示注入方式**（`promptda/model/blocks.py`）：
  - 4 个解码层级各有一个 `resConfUnit_depth` 分支：3×3 卷积，单通道输入，最后一层零初始化；
  - 提示先用 bilinear 插值到各层分辨率再注入，错误值和空洞会被平滑扩散到邻域。
- **PromptDA 已有透明物体版本**：官方发布了 `prompt-depth-anything-vits-transparent`，是在 HAMMER 上用 iPhone LiDAR 模拟微调了 10K 步的 Small 模型。它是必须比较的基线；也正因为它见过 HAMMER，只能在 HAMMER 的测试场景上评测它，并在表中注明。
- **PriorDA 的结构**：
  - 粗对齐阶段用 `torch_cluster.knn` 找近邻点，再做最小二乘求尺度/平移，不排除离群点；
  - v1.1 把条件输入从误差图换成稀疏掩码；
  - 提供 `coarse_only` 接口，可以单独拿到粗对齐结果做对照。
- **HAMMER**：
  - 共 13 个场景，scene2–11 训练、scene12–14 测试；
  - 三种传感器（D435 主动立体、L515 d-ToF、Helios i-ToF）的深度都已前向 warp 到 RGB 视角，并配有渲染真值；
  - 另有同视点、拿走物体的 `naked` 轨迹，可以直接给出“透过透明物体看到的背景深度”。

### 1.3 统一样本格式（`tp/data/schema.py`）

每帧一个 `npz`。论文里的所有数字都只从这个格式读，不再各数据集各写一套评测。

```python
@dataclass
class Sample:
    rgb: np.ndarray            # uint8 [H,W,3]，RGB 原生分辨率
    prompt: np.ndarray         # float32 [h,w] 米；传感器原生分辨率，已配准到 RGB 视角
    prompt_valid: np.ndarray   # bool [h,w]（0/NaN/超量程 -> False）
    prompt_conf: np.ndarray | None  # 传感器置信度（ARKit 0/1/2），没有则 None
    gt: np.ndarray             # float32 [H,W] 米，第一表面
    gt_valid: np.ndarray       # bool [H,W]
    material: np.ndarray       # uint8 [H,W]：0 未知，1 普通，2 镜，3 玻璃/透明，4 金属
    K_rgb: np.ndarray          # 3x3
    K_prompt: np.ndarray       # 3x3（prompt 网格对应的内参）
    sensor: str                # 'kinect1','mp3d_sl','structure','d435','l515','helios','iphone','realsense_cg'
    dataset: str; scene: str; frame: str; split: str   # split 按 scene 划分
    behind: np.ndarray | None  # 可选：透明物体背后的深度（HAMMER naked），模拟用
```

约定：
- 深度一律是相机轴向 Z，单位米；`prompt` 不做任何补洞，空洞由 `prompt_valid` 表达。
- 每个数据集的 loader 都要写一个 3–5 帧的对齐检查：把 prompt 投到 RGB 上看边缘、核对内参、核对编号。Mirror3D-NYU 错位一帧就是这类问题。

## 3. 评测实现（第 2–4 天，Claude 写，学生 A 核对）

### 3.1 区域定义（`tp/eval/regions.py`）

所有区域只由传感器提示和真值决定，与被评方法无关，保证各方法的分母一致。

```python
def regions(P_up, Pv_up, gt, gtv, tau=0.05, band=5):
    # P_up：提示最近邻上采样到 RGB 分辨率；Pv_up 同理
    both = Pv_up & gtv
    rel = np.abs(P_up - gt) / gt
    C   = both & (rel > tau)                 # 污染：提示有效但错误
    Cfar  = C & (P_up > gt)                  # 偏远（穿透/虚像），危险类
    Cnear = C & (P_up < gt)                  # 偏近（多径/飞点）
    clean = both & ~C
    hole  = (~Pv_up) & gtv                   # 提示缺失
    B = dilate(boundary(C), band) & gtv      # 污染区边界环带
    return dict(C=C, Cfar=Cfar, Cnear=Cnear, clean=clean & ~B, hole=hole, band=B, all=gtv)
```

τ 主用 0.05，敏感性分析另报 0.02 和 0.10。

### 3.2 指标（`tp/eval/metrics.py`）

- 每个区域报告度量 AbsRel、RMSE、log-RMSE、δ<1.05/1.10/1.25，**不做任何尺度对齐**。为了和文献可比，另报一列仿射对齐后的结果，但主表只放度量结果。
- **继承率** IR = 在 C 区域内，满足 |D̂−P|/P<0.05 且 |D̂−GT|/GT>0.05 的像素比例。
- **危险高估率** DOR = 在 C∪band 内，D̂ > 1.10·GT 的像素比例，对应“把障碍物看远了”。
- **可信度质量**：w 对 1[clean] 的 AUROC/AUPR；风险–覆盖曲线（按 w 排序后保留前 x% 像素的 AbsRel）。
- **聚合方式**：先逐图求指标，再在场景内平均，最后跨场景平均。像素数为 0 的区域记为 NA，不记 0。

### 3.3 统计（`tp/eval/bootstrap.py`）

- 场景级配对 bootstrap，10,000 次，报告 95% CI；跨数据集比较用 Holm 校正。
- `make_tables.py` 从逐图 json 直接生成 LaTeX 表格，论文中任何数字都不手抄。

### 3.4 必要单元测试（只写这些）

- 反投影 / 投影往返误差；
- 平面 1/Z 拟合在合成倾斜平面上精确；

- PromptDA 改造后在零初始化下与原模型逐值相等。

## 4. 污染模拟器（第 4–9 天，学生 A + Claude）

模拟器对每个训练样本输出 `(P_clean, P_corrupt, corrupt_type_map)`。`P_clean` 来自真值经过传感器模型，`P_corrupt` 在此基础上叠加 0–3 处非朗伯污染。

### 4.1 传感器基础模型（`tp/sim/iphone.py` 等）

- **iPhone LiDAR**：
  1. 真值按区域**最小值池化**到 256×192（LiDAR 返回最近表面）；
  2. 加距离相关高斯噪声 σ(z) = a + b·z²。a、b 用 ARKitScenes 干净区域拟合：对“iPhone 深度 − Faro 真值”按距离分箱求标准差，再做二次拟合；
  3. 深度不连续处（|∇ log z| 大）生成飞点：以概率 p_fly 取前景和背景的随机凸组合；
  4. 合成置信度图：飞点和远距离区域置 0/1，其余为 2；
  5. 距离 >5 m 时按概率置为空洞。
- **结构光 / 主动立体**：
  - 原生分辨率，按 z² 增长的量化噪声；
  - 边缘空洞：沿深度跳变外侧膨胀 2–6 像素置空；
  - 暗色/低纹理区域随机空洞。
- **ToF**：多径正偏差（凹角处 +1–5%）+ 飞点。

不追求逼真到物理级别。真实传感器数据本身就是主评测集，模拟器只负责覆盖训练分布。

### 4.2 穿透（玻璃/透明）

对掩码 Ω_t：
- 有 `behind` 的样本（HAMMER naked）：`P_corrupt[Ω_t] = behind`，再经过传感器模型；
- 否则构造背景：在 Ω_t 外膨胀一圈的环带上，取最远的那组支持面拟合 1/Z 平面（桌面或墙面），外推到 Ω_t 内作为背后深度；若环带不共面，就用环带深度的 80% 分位常数代替；
- **混合模式**（概率 0.3）：逐像素以概率 α~U(0.3, 0.8) 取背景，其余取表面，模拟光斑覆盖玻璃边缘或部分透射。

### 4.3 反射（镜面）：`tp/sim/mirror_render.py`

对一个平面区域 Ω_m，平面为 π: n·X = d（从真值拟合，或在随机选取的墙面子区域上定义）。镜中虚像的深度按下面的算法渲染：

```python
X = backproject(gt, K)                       # 场景点云，排除 Ω_m 自身
Xv = X - 2 * ((X @ n) - d)[:, None] * n      # 关于镜面平面做反射
Z_v = zbuffer_render(Xv, K, H, W)            # 用原相机渲染（最近点）
valid = (Z_v > depth_of_plane_along_ray) & np.isfinite(Z_v)   # 虚像必在镜面之后
P_corrupt[Ω_m] = np.where(valid, Z_v, hole_or_far)[Ω_m]
```

- 渲染结果正确对应“相机能看见的那部分场景”的镜像。相机背后的内容渲染不出来，按 50/50 随机处理成空洞或远距离常数；这个缺陷在论文里写明。
- 实现上用 PyTorch 的 scatter-min 做 z-buffer，GPU 上一帧约毫秒级 [估算]。
- 渲染出的虚像应当处处在镜面之后：做一次符号检查，违反的像素一律置空洞。

### 4.4 金属

对掩码 Ω_x：以 p∈[0.2, 0.7] 随机掉点；剩余像素乘以 (1+δ)，δ~U(0.01, 0.10)，同时叠加高频斑点噪声。

### 4.5 区域选择与比例

- 有真实材质掩码就用掩码；没有就从平面区域（RANSAC 平面面积 >2% 图像）和物体实例中随机选。
- 每个训练样本以 0.6 的概率施加污染：类型按穿透 0.4、反射 0.4、金属 0.2 抽样，覆盖面积占图像 2–60%。
- 对大面积污染（>30%）适当过采样，因为免训练基线在这种情况下会失败，正是方法需要证明的地方。
- 同时生成逐像素类型标签：0 干净、1 偏远（穿透/反射）、2 偏近（多径/飞点）、3 空洞。

## 5. 方法实现

### 5.1 模块 A：冻结先验 + 鲁棒对齐（`tp/align/robust.py`，不学习）

1. **单目先验**：主用 DA3-mono 或 DAv2-L 的相对视差 `m`；度量版本用 UniDepthV2 作消融。推理一次后缓存到磁盘（fp16，每帧约 0.5 MB [估算]）。
2. **全局鲁棒对齐**：在提示有效像素上，用 RANSAC 在视差空间拟合 `1/P ≈ s·m + t`，取 1000 次迭代、内点阈值 5% 相对误差，再用内点做 IRLS-Huber 精修。得到 `D_g`。
3. **逐块鲁棒对齐**：图像分成 8×8 网格，每块和它的 3×3 邻块组成支持集，做同样的 IRLS-Huber 拟合，得到逐块 (s, t)；内点数过少的块继承全局解。对 (s, t) 做双线性插值，避免块状伪影，得到 `D_a`。
4. **输出给可信度网络的特征**：
   - `r = log P − log D_a`（逐像素残差）、`r_g = log P − log D_g`；
   - 逐块内点率、残差 MAD；
   - 局部解与全局解在该块上的分歧 `|log D_a − log D_g|`。

这一步本身就是 GlassRecon / AnchorD 思路的复现，同时作为基线 `RobustAlign`。

### 5.2 模块 B：可信度网络 T（`tp/models/trust_net.py`）

- **工作分辨率**：378×504（14 的倍数）。提示按最近邻上采样到该分辨率，有效掩码同步处理。
- **输入**：
  - 冻结 DINOv2-S 的最后一层特征（384 维，1/14 分辨率），1×1 卷积投影到 64 维，上采样到 1/4；
  - 提示分支 9 个通道：`log P` 减去图内中位数、`valid`、`r`、`r_g`、`|∇log P|`、3×3 局部方差、逐块内点率、逐块分歧图、传感器置信度。没有置信度的传感器在置信度通道全填 −1。
  
  传感器类型**不作为输入**，否则会损害留一传感器的泛化。
- **结构**：轻量 U-Net，编码通道 32/64/128/256，3 级下采样，每级两个 3×3 卷积 + GroupNorm + GELU。在 1/4 尺度与 DINO 特征拼接，在瓶颈层加 2 层窗口自注意力（窗口 8×8），用来看到较大的污染区域。参数量约 5–8M [估算]。
- **输出头**：
  - `w = sigmoid(·)`：提示可信度；
  - `type_logits`：4 类，即干净 / 偏远 / 偏近 / 空洞；
  - `w` 下采样回提示网格时用 3×3 **最小值池化**，宁可多怀疑一点。
- **标签**（只在 `gt_valid ∧ prompt_valid` 处计损失）：
  - `y = 1[|P−GT|/GT ≤ τ]`，τ = 0.05；
  - 另有软标签 `ỹ = exp(−(|log P−log GT|/0.05)²)`；
  - 类型标签由真值算出，或直接取模拟器给的类型。
- **损失**：`L_T = FocalBCE(w, y; γ=2) + 0.5·BCE(w, ỹ) + 0.3·CE(type)`。真实数据里干净像素占绝大多数，对污染像素按逆频率加权，权重上限 20。
- **训练**：DINOv2-S 冻结，单目先验与对齐结果预先算好并缓存，所以训练非常便宜。设置为 AdamW、学习率 3e-4、批大小 32、余弦退火 30k 步，单卡 A100 约 4–6 小时 [估算]。

### 5.3 模块 C：低自由度区域填充（`tp/models/fill.py`）

对 `w<0.5` 的连通域 Ω 先膨胀 3 像素，再取外环 R = dilate(Ω, 10) \ Ω，要求环上像素满足 `w>0.7` 且提示有效。在环 R 上拟合 5 个候选，统一在视差空间计算：

| 档位 | 候选 | 自由度 | 拟合方式 |
|---|---|---|---|
| k0 | `D_a`（逐块对齐后的先验） | 0 | 直接使用 |
| k1 | `s·m` | 1 | 环上加权中位数比值 |
| k2 | `s·m + t` | 2 | 环上 IRLS-Huber |
| k3 | 平面 `1/Z = a·u + b·v + c` | 3 | 环上的提示点（反投影后）做 IRLS 平面拟合 |
| knp | 不填，交给补全网络 | — | — |

**选择规则 v1（不学习）**：
- 先算每个候选的环上鲁棒残差 RSS，以及 BIC = n·log(RSS/n) + k·log n；
- k3 要额外检查一项：用 k2 得到的先验深度在 Ω 内部是否也近似平面（平面拟合相对残差 <2%）。只有内外都平才选平面，避免把曲面物体当平面填；
- 环上可用点少于 50 个时，退回 k0。

**选择规则 v2（学习，第 3 周加入）**：选择头读取 T 在 Ω 上池化的特征和 5 个候选的环残差，输出 softmax，训练标签为对 Ω 真值 AbsRel 最好的候选（交叉熵）。推理时取 argmax。这样“自由度”本身成为一个可报告的受控变量，延续了原 R1 的思路。

**输出**：`D_fill`（Ω 以外等于 `D_a`）和 `fill_choice` 图（供可视化与消融使用）。

### 5.4 模块 D：改造后的 PromptDA（`tp/models/promptda_trust.py`）

三处改动，都保证在零初始化时与原模型逐值相等：

1. **提示重写**：`P' = w_p·P + (1−w_p)·D_fill`（`w_p` 为提示网格上的可信度）；提示空洞处直接取 `D_fill`。这样不会再把 0 送进网络。
2. **可信度通道注入**：把 4 个 `resConfUnit_depth` 的第一层 `Conv2d(1, F)` 换成 `Conv2d(2, F)`。新卷积第 0 通道拷贝原权重，第 1 通道权重置零；输入为 `[P'_norm, w_p]`。初始化时输出与原模型完全相同，微调时才学会使用 w。另外，提示插值改为“有效掩码加权插值”：分别插值 `P'·valid` 和 `valid` 再相除，避免空洞把邻域拉低。
3. **鲁棒归一化**：把 0/100% 分位数换成在可信像素（`w_p>0.5`）上取的 1%/99% 分位数，并把上界放宽到 ×1.25，让输出可以超出提示范围。由于数值分布变了，这一改动必须配合微调。消融里单独报告“只改归一化、不微调”的结果。

```python
class TrustPromptDA(PromptDA):
    def normalize(self, P, w):
        m = (w > 0.5) & (P > 0)
        lo = masked_quantile(P, m, 0.01); hi = masked_quantile(P, m, 0.99) * 1.25
        return (P - lo) / (hi - lo).clamp_min(1e-3), lo, hi
    def forward(self, x, P_prime, w_p):
        Pn, lo, hi = self.normalize(P_prime, w_p)
        feats = self.pretrained.get_intermediate_layers((x - self._mean) / self._std,
                    self.model_config['layer_idxs'], return_class_token=True)
        ph, pw = x.shape[-2] // 14, x.shape[-1] // 14
        d = self.depth_head(feats, ph, pw, torch.cat([Pn, w_p], 1))   # 2 通道提示
        return self.denormalize(d, lo, hi)
```

### 5.5 训练配方

**数据混合**（每个批次按比例抽样）：

| 来源 | 比例 | 说明 |
|---|---|---|
| Hypersim + 模拟污染 | 40% | 主要训练源 |
| ARKitScenes 真实 iPhone 提示 | 20% | iPhone 域 |
| HAMMER train（三种传感器轮换） | 20% | |
| Mirror3D train（MP3D/ScanNet 获批后加入，否则只用 NYU train） | 20% | |

留一传感器训练时，被留出的那类传感器的全部真实数据都从训练集中移除。模拟器继续使用，但关闭对应传感器的噪声模型。

**三个训练阶段：**
- **阶段 1：只训 T**（§5.2），全部特征都有缓存。
- **阶段 2：冻结 T，微调补全网络**：
  - DINOv2-L 编码器加 LoRA（rank 16，作用于 qkv 和 proj）；
  - DPT 解码器全部参数可训，学习率为 LoRA 的 0.1 倍；
  - 训练分辨率 504×672 随机裁剪，提示保持传感器原生网格；
  - AdamW，LoRA 学习率 1e-4，批大小 8（梯度累积到 16），bf16，梯度检查点，20k 步；
  - 单卡 A100 约 12–18 小时 [估算]。
- **阶段 3（可选）：端到端精调**。T 学习率 1e-5，总损失再加 `L_T`，5k 步。

**补全损失**（只在真值有效处计算）：

```text
L_depth = mean_i  ω_i · |log D̂_i − log GT_i|,   ω = 1 + 2·1[C] + 1·1[band]
L_grad  = Σ_s mean |∇(log D̂ − log GT)| on scales s ∈ {1, 1/2, 1/4, 1/8}
L_inv   = mean |log f(I, P_corrupt) − stopgrad(log f(I, P_clean))|      # 仅对模拟样本
L_safe  = mean_{C_far ∪ band} relu(log D̂ − log GT − log 1.05)          # 只惩罚高估（危险方向）
L = L_depth + 0.5·L_grad + 0.2·L_inv + 0.2·L_safe   (+ 0.5·L_T in stage 3)
```

`L_inv` 的计算方式：同一张图做两次前向，一次用干净提示，一次用污染提示，干净分支不回传梯度。它直接针对“继承”：输出不应随错误提示而变。

**推理**：先跑先验和对齐 → T → 填充 → TrustPromptDA，一次前向完成。最终可信度输出为 `u = 1 − w`，并在填充区域加上候选间的分歧。下游需要保守深度时（导航），可另外输出 `D_safe = min(D̂, D_fill)`，单独评测它的危险高估率。

## 7. 工程实现要点

1. **缓存三类中间结果**，都只算一次，按 `dataset/scene/frame.npz` 存在云盘：
   - 单目先验（fp16）；
   - 鲁棒对齐结果与残差特征（fp16）；
   - DINOv2-S 特征（384×27×36 fp16，约 0.75 MB/帧 [估算]）。
   
   T 的训练只读这些缓存，不再跑任何大模型前向。PromptDA-L 微调需要在线前向，不缓存。
2. **数据管线**：先把原始数据集离线转成 §1.3 的 npz，再打包成 WebDataset 分片（每片约 1 GB），放在云实例本地 NVMe 上；DataLoader 开 16 个 worker，并启用 pin_memory。
3. **吞吐**：
   - 混合精度 bf16；
   - PromptDA-L 微调时，DINOv2 的 24 层都开梯度检查点；
   - 先确认 xformers 的 memory-efficient attention 已经生效，再开始长训练（打印一次 attention 后端即可）。
4. **云端使用**：
   - 开发期 1×A100 按需实例；
   - 消融批量跑在竞价实例上，每 30 分钟同步一次 checkpoint 和优化器状态，被回收后自动续跑；
   - 评测在 1–2 卡上一次性跑完所有方法 × 数据集，生成逐图 json。
5. **可复现**：每次训练记录 git commit、配置文件、随机种子、数据清单；评测 json 带上 checkpoint 路径。不做哈希和封存。
6. **本地 4070**：
   - 跑单元测试、模拟器可视化、Stray Scanner 数据转换；
   - 用 PromptDA-S 和 384 分辨率做“能不能跑通”的冒烟测试；
   - 大模型推理和训练都放在云上。

## 8. 自采 iPhone 测试集（第 2–3 周并行，学生 A）

1. **设备与软件**：iPhone Pro + 三脚架 + 手机夹；App 用 Stray Scanner（PromptDA 官方支持其格式，能导出 RGB、256×192 深度、置信度、内参、位姿）；另购一个激光测距仪（几十美元）用于抽查绝对精度。
2. **每个场景的流程**：
   1. 固定三脚架位姿；
   2. 采集 A：在镜面/玻璃上贴 6–12 片可移除哑光标记（美纹纸方块），覆盖平面的四角和中部，录 3 秒；
   3. 不动三脚架，撕掉标记，录 3 秒，作为采集 B；
   4. 在每个视点重复以上步骤，每个场景 3–5 个视点。
3. **真值构造**：
   - 从 A 的深度中取标记处的点（标记位置在 RGB 上手点或用颜色阈值分割），反投影后用 RANSAC 拟合平面；
   - 在 B 中，对镜/玻璃掩码内的每条像素射线与平面求交，得到第一表面真值；
   - 镜/玻璃掩码在 B 的 RGB 上手工描多边形，每张约 1 分钟；
   - 掩码外的普通区域取 B 中置信度为 2、距离 <3 m 的 LiDAR 深度作伪真值，在表中注明“伪真值”。
4. **质量检查**：
   - 两次采集在背景区域的深度差（衡量三脚架稳定性），超过 1 cm 就重拍；
   - 激光测距仪对平面中心测距，与平面真值比较；
   - 同一平面用不同标记子集拟合，看结果的一致性。
5. **规模**：15–20 个场景（镜子、玻璃门、窗、展柜、玻璃桌面），共约 60–80 帧，只作测试集。金属家电只做定性展示。

## 11. 算法提升清单（按实现顺序；每项写明针对的瓶颈和应观察到的变化）

1. **提示重写 + 填充（无需训练）** → 瓶颈：错误提示直接进入网络。预期：不微调的 PromptDA-L 在 C 区域的 AbsRel 与 IR 明显下降，干净区域基本不变。
2. **鲁棒归一化** → 瓶颈：min/max 被虚像深度和空洞拉偏，输出受提示范围约束。预期：镜面图像整图误差下降，尤其是虚像深度远大于场景最大深度的帧。
3. **可信度通道注入** → 瓶颈：网络无法区分“填充出来的提示”和“传感器测得的提示”。预期：填充区域与真实区域交界处（band）的误差下降。
4. **掩码加权插值** → 瓶颈：bilinear 插值把空洞和错误值扩散到邻域。预期：band 区域误差下降。
5. **L_inv 不变性损失** → 瓶颈：微调后模型仍对提示过度信任。预期：IR 下降，且在留出传感器上下降更多。
6. **L_safe 非对称损失** → 瓶颈：高估比低估更危险。预期：DOR 下降，可能伴随 Cnear 略升，两者都要报告。
7. **学习式填充选择（v2）** → 瓶颈：规则在“无边框镜面”“曲面玻璃”上选错档。预期：T4 中透明物体与无边框镜面的误差下降。
8. **T 的大感受野（窗口注意力）** → 瓶颈：大面积镜面内部的残差在局部看起来是自洽的。预期：污染面积 >30% 的分桶中 AUROC 上升。
9. **可信度温度校准**（在 val 上做一次温度缩放）→ 瓶颈：w 的数值不是概率。预期：可靠性图更接近对角线，风险–覆盖曲线不变。
10. **时序一致性特征**（留给 ICCV）→ 瓶颈：单帧无法区分“镜中虚像”和“真实远处物体”。预期：镜面上的 AUROC 明显上升。

## 13. 已知风险与对应处理（不作为停止条件，只是预案）

- **MP3D/ScanNet 协议迟迟未批**：镜面真实数据只剩 NYU 125 张与自采数据，统计力不足。处理：镜面训练改为模拟反射 + NYU train；镜面测试以自采数据为主，并在论文中如实说明。
- **HAMMER 许可不明**：先邮件询问作者；收到回复前只在内部使用，不公开衍生数据。
- **PromptDA-L 微调显存**：504×672、批大小 2/卡、开梯度检查点可装进 80GB [估算]；不够时降为批大小 1 加梯度累积，**不降分辨率**。
- **模拟到真实的差距**：主表只用真实传感器数据；模拟器只是训练手段。T3 里报告“只用真实数据训练”的版本。
- **同类工作突然出现**：每周检索一次。若出现，把重心移到留一传感器泛化、继承机制分析和 C1 的评测协议上。
