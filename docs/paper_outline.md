# 论文提纲（方案 A，2026-10-29；草稿）

状态：**提纲草稿**。下文的数字都是开发集诊断（test 从未读取），引用的文件里有完整表格。投稿前缺的部分列在第 7 节。

## 0. 一句话

带深度提示的补全模型，会把镜面和透明物体上成片测错的传感器深度“照单全收”（提示继承）。我们给出度量这一现象的协议，提出一个模型无关的可信度检测器 T，并用 conformal 风险控制给出屏蔽规则的保证；它在 6 个补全模型上都显著降低了错误区误差。我们还研究了“把检测训练进补全网络内部”这条路，发现了阻碍它的两个机制。

## 1. 问题与定位

- 现象：提示式深度补全（PromptDA、PriorDA、OMNI-DC、CDM、LingBot-Depth、Any2Full、Marigold-DC）默认信任传感器深度。在镜面和玻璃上，深度会成片测错，而且 96–99% 是测远了（反射、透射使光程变长）。
- 相关工作（`docs/related_work_audit.md`）：
  - DEPTHOR++ 做一致性检测，但作者承认在大面积均匀区域会失效；
  - OMNI-DC 有内部置信度，但承认在玻璃和反射表面上出错；
  - LingBot-Depth 只屏蔽无效像素；
  - CDM 的纠错是隐式的。
  - 都没有量化继承，也没有给出屏蔽的保证。
- 不声称的：屏蔽 + 先验填充本身（DEPTHOR++、PriorDA 已有）；提示修复（与 Mirror3D 真值同源）。

## 2. 贡献（按证据强度排序）

1. **测量**：定义继承率 IR 和危险高估率 DOR，按提示误差定义污染区 C（τ = 0.05）；固定分母、无尺度对齐的米制评测协议；跨模型、跨传感器测量（`docs/c1_analysis.md`）。
   - 规律：继承随污染面积上升。NYU 镜面面积与 PromptDA-L 继承率的 Spearman ρ = 0.49；面积 5–20% 时中位继承率 0.93。HAMMER 上小而分散的污染基本不被继承。
2. **检测 T，即插即用**：在 6 个模型上都显著降低错误区误差（预注册的 Holm 检验族，`docs/holm_plugin_v1.md`、`docs/holm_plugin_cf_v1.md`）。
   - NYU val：6/6 显著。例如 OMNI-DC 0.750 → 0.137，PromptDA-L 0.467 → 0.096。
   - HAMMER 跨场景交叉拟合（10 个场景、场景级 bootstrap）：4/6 显著；PromptDA-L 不显著，CDM 缺失。
   - Marigold-DC（扩散式引导，`docs/holm_marigold_nyu_v1.md`）：val 0.579 → 0.157，留出 1.088 → 0.046。
3. **保证**：用 conformal 风险控制选屏蔽阈值，控制“未被标记的危险（测远）像素比例”。α = 0.1 时 NYU 和 HAMMER 的 val 都满足（`docs/conformal_results_d20.md`）。α = 0.2 时 HAMMER 不满足，要如实报告。
4. **分析：为什么不直接把检测训练进网络**（第 5 节）。这一部分是本轮工作的新结论，可以作为重要的分析章节。

## 3. 方法（方法 v1，结构和规则冻结）

- UniDepthV2-S 鲁棒全局对齐得到 D_g → T 输出逐像素可信度 → conformal 阈值（α = 0.1，按数据集标定）→ 屏蔽不可信提示，用 D_g 填充 → 任意补全模型。
- T 的设计与训练：物理污染模拟器 + 真实数据；无编码器特征版本（避免泄漏）。附录给出 T v2 的方向输出（可解释性）。
- 待做：冻结 T 的权重（第 7 节）。

## 4. 实验

- 数据：NYU Mirror3D（场景级划分 55/18/23）、HAMMER（10 个开发场景，3 种传感器）。test 只在方法冻结后跑一次。
- 对比：每个模型分别报告原始输入、接 T 掩码、GT 掩码（神谕）三种设置；另有 DEPTHOR++ 检测器。
- 主表：错误区 AbsRel、IR、DOR，带 bootstrap 区间和 Holm 校正。
- 必须同时报告的代价：干净像素。
  - 在 NYU 镜面内的干净像素上，屏蔽会明显变差（OMNI-DC +439%，PromptDA-L +46%）。原因是 T 把整面镜子都标记了，而镜面上偶尔正确的读数也被删掉。这类像素只占镜面的约 3%。
  - HAMMER 上干净像素基本不变或略好。
  - 这项代价在第 5 节的内化方案中同样存在（F1+ 为 +438%），说明它属于“镜面先验”本身，不是 T 独有的问题。
- 消融：阈值规则（模型阈值与 conformal 比较）、填充方式、T 训练数据（真实、仿真、两者结合）、按传感器分解。

## 5. 分析：把检测训练进补全网络（OMNI-DC 主线的负结果）

所有数字都在 `docs/plan_omnidc.md` §16–24。

1. **设置**：在 Hypersim 上合成镜面和窗户的结构化错误（D3 检查与真实统计相符），微调 OMNI-DC：F1 用合成错误，F0 不用（对照）。
2. **能学会检测**：F1 的输入置信度在 NYU 镜面上的 AUROC 从 0.52 升到 0.91，与外接 T 相同；错误区相对 F0 下降 90.7%（NYU）和 27%（HAMMER）。
3. **但代价是整张图的精度**：对正确读数的置信度从 0.99 降到 0.62，镜面外干净区误差约为 F0 的 15 倍。预注册的非劣判据 G3 未通过。
4. **机制一：信任与纠正耦合**（推理时替换置信度，`docs/omnidc_p1_coupling.md`）。
   - 只把正确读数的信任还回去，NYU 上可消除 69% 的干净区损失，HAMMER 上约 89%，错误区不变差。
   - 但把 F1 的置信度交给 F0 的网络，错误区毫无改善：纠正是 F1 的深度通路学出来的。
   - 推理时的 conformal 信任下限也救不回来（λ 标定为 0）：F1 置信度最低的那一档里，正确和错误读数混在一起。
5. **机制二：镜面先验**。即使完全信任读数，F1 在镜面内正确读数上的误差仍很大：它学到了“看起来像镜面，读数就不对”。真实和合成镜面里正确读数都只占约 3%，模型没有机会学到例外。
6. **标签的影响**（本机预检，`docs/omnidc_p1v2_precheck_long.md`）：按比例的置信度标签在相同步数下各项都更好，但只能减轻、不能消除上述下降。
7. **结论**：内化之后检测能力并不差，但在 OMNI-DC 这类“置信度即权重”的结构里，信任与纠正共享同一个通道。要真正受益，需要把两者分开并联合训练，这是一个开放问题。这正好说明为什么外接 T + 风险保证在现阶段更可靠。

## 6. 局限

- Mirror3D 的真值由镜框平面拟合得到，与平面填充同源；NYU 上平面类方法的收益可能偏高。主要证据应放在非平面真值的数据上。
- NYU 划分不是 Mirror3D 官方划分；要与已发表数字比较，需要按官方划分重做。
- HAMMER 只有 10 个开发场景；conformal 的可交换性是假设，没有验证。
- 开发集被反复使用；最终结论以冻结后的 test 为准。
